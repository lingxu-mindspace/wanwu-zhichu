# 接引仪式设计文档

> 依据：GDD 第一卷 §3.3「接引仪式形态」
> 本文档补全：各文化区具体仪式形态、触发条件、玩家体验、视觉指引

---

## 一、设计原则

1. **仪式是真实事件，不是过场动画**。参与者的行为影响仪式进程，部分仪式可被外力中断。
2. **仪式形态由封神者的文化底色决定**，不由神位决定。
3. **仪式是世界级事件**，一旦触发全服广播。附近玩家可赶来观礼，分享见证的功绩。
4. **仪式失败是可能的**——被半神突袭、玩家破坏、或接引者操作失误。

---

## 二、通用流程

```
封神资格确认 → 成神之兆(3天公示) → 接引仪式(实况事件) → 封神完成
```

### 2.1 成神之兆（3天公示期）

- 全服广播："天道感应，某处有封神之兆显现"——不公布具体玩家和地点
- 72小时（现实时间）内封神者无法隐藏光环效果
- 公示期内封神者可被击杀——击杀者承受极重过失（×10）
- 被封神候选人被杀，成神之兆消失，功绩减半，需重新积累

### 2.2 接引仪式三阶段

1. **降临**：接引者以神临方式出现在封神者所在区域
2. **试言**：接引者向封神者提出三个问题（文化区决定主题）
3. **授号**：授予神之称号，天道系统确认封神

## 三、各文化区仪式形态

### 3.1 中原文化圈

**成神之兆**：五色光芒（青赤黄白黑），龙形气旋，编钟之音。

**降临**：接引者乘龙车自天而降。龙车为虚体（不可攻击），伴随天雷与祥云。

**试言三问**：
1. "汝以何功，敢问天位？"（自述最大功绩）
2. "汝之过失，何以自赎？"（面对过失轴）
3. "天下苍生，汝何以待之？"（承诺神职态度）

**授号**：接引者以玉圭点眉心，金光盘升入神域。原身遗落一件遗物。

### 3.2 北欧文化圈

**成神之兆**：周身雷电，双眼金光，头顶永不落下的极光。

**降临**：彩虹桥（Bifröst）投影降下。

**试言三问**：
1. "汝以何武勇，证汝之名？"（展示战力）
2. "汝之誓约，可曾背弃？"（核验过失轴中誓约相关条目）
3. "英灵殿中，汝欲与谁共饮？"（体现荣耀观）

**授号**：冈格尼尔之影刺入心脏（视觉效果），凡躯化金光重组为神体。

**特殊规则**：曾击杀北欧半神者，被击杀半神的同族可提出"血仇挑战"（1v1）。

### 3.3 希腊罗马文化圈

**成神之兆**：足下生火不灼烧，说话有回声，月桂叶冠冕虚影。

**降临**：赫尔墨斯形象——双翼鞋、盘蛇杖，身后星光轨迹。

**试言三问**：
1. "汝之悲剧，成就了何等智慧？"
2. "汝可曾傲慢？汝可曾谦卑？"
3. "奥林匹斯山上，汝欲添何名？"（自定神名）

**授号**：月桂枝冠冕燃为金色烈焰，焚尽凡躯，神体自火焰中新生。

**特殊规则**：仪式期间所有敌对者获得"神谴挑战权"——可发出质疑，由天道系统判定。

### 3.4 埃及文化圈

**成神之兆**：皮肤金色微光，影子变为鹰首人身，预知梦。

**降临**：阿努比斯形象——胡狼头、天秤、金色项圈，身后黑色沙径。

**试言三问**：
1. "汝之心，可经天秤称量？"（核验功过比）
2. "汝之真名，可敢公示于众？"（**唯一公开真实身份的仪式**）
3. "汝愿以何物，守护玛阿特？"（选择献祭的法则之力）

**授号**：心脏置于天秤一端，玛阿特之羽置另一端。天平平衡则封神。

### 3.5 印度文化圈

**成神之兆**：千瓣莲花虚影，眉间第三只眼，檀香。

**降临**：梵天形象——四面四臂，手持吠陀经卷，从头顶虚空展开。

**试言三问**：
1. "汝经历了几世轮回，方才至此？"
2. "汝之业力，可曾清净？"
3. "梵我合一，汝舍弃了什么？"（公开宣布将舍弃的凡间之物）

**授号**：梵音念诵神名，肉身化作万千莲花瓣，神体自花蕊显现。

### 3.6 日本文化圈

**成神之兆**：八方神灵注视——八朵颜色各异的光球，每次睡眠梦见神明的寄语。

**降临**：天照大神使者——白狐面具、绯红和服、八咫镜虚影。

**试言三问**：
1. "汝之穢，可曾祓除？"（净化仪式）
2. "八百万神，汝欲列于何处？"（选择神域：天/地/幽冥/海/山）
3. "此世与彼世，汝之桥梁如何架设？"

**授号**：八咫镜照向封神者，镜中倒影与本体合二为一。

**特殊规则**：曾与任何日本神灵交往者，该神灵可在仪式中"发言"祝福或警告。

### 3.7 凯尔特文化圈

**成神之兆**：头发变槲寄生色，足印中长出迅速枯萎的花，动物主动接近。

**降临**：达格达形象——巨大身影、魔棒、永不枯竭的大锅。

**试言三问**：
1. "汝之誓约，可曾缚汝之魂？"（Geis系统核验）
2. "汝以诗歌传颂谁人之名？"（即兴创作短诗）
3. "永恒之锅中，汝献上何物？"（献出一件随身物品，被销毁）

**授号**：魔棒轻触心脏→永恒年轻。脚下升起山楂树，爬入树冠光雾进入神域。
